# Mass-Personalization-in-Recommender-Systems-Independent-Research

Inspired by repetitive patterns in the Spotify Wrapped for 2024, I explored how mass personalization affects user experiences on digital platforms. Using Amazon product ratings, I developed a Python-based data analysis framework (recommender system simulation) to track user overlap patterns over 20+ years, applying AI/ML collaborative, content-based, and hybrid filtering techniques to study recommendation trends. My analysis revealed increasing convergence in product recommendations from 2013–2021, highlighting how recommender systems can unintentionally create echo chambers and reduce content diversity. This project strengthened my skills in artificial intelligence & machine learning, Python, data analysis, and visualization, while deepening my understanding of how AI systems operate and the importance of designing more inclusive and novel user experiences. I had the opportunity to present my research process and findings to the Computer Science Department in Spring 2025.
